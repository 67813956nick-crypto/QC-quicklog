# QC-quicklog 材料质量证明文件快速录入

石化项目材料质量证明文件（质保书/合格证）快速录入工具。上传 MinerU 解析的 JSON 文件，自动解析阀门、对焊法兰、管材、紧固件、垫片、管件、支吊架等物资信息，补填自编号后一键导出底表与 SH/T 3503—J132 一览表。

## 物资分类（7类）

| 分类 | 识别关键词 | 默认单位 |
|---|---|---|
| 阀门 | 闸阀/球阀/蝶阀/截止阀/止回阀 | 台 |
| 对焊法兰 | 法兰/FLANGE | 片 |
| 管材 | 钢管/无缝/焊管/流体输送 | 吨/KG/m |
| 紧固件 | 螺栓/螺柱/螺母 | 套 |
| 垫片 | 缠绕垫/垫片 | 件 |
| 管件 | 弯头/三通/大小头/管帽/管箍等 | 件 |
| **支吊架**（V7.4新增） | 吊架/支吊架/碟簧吊架/弹簧支架 | 套 |

> 支吊架独立分类，**不属于管件**（如可变碟簧吊架）。

## 使用

1. 用浏览器打开 `材料录入桥接工具_v7.4.html`
2. 上传 MinerU 解析出的 JSON 文件（见 `tests/fixtures/` 样例格式）
3. 解析结果自动填入底表，可手动补填「证件自编号」「复验报告编号」
4. 导出：底表 CSV / 一览表 CSV / JSON

> 单 HTML 文件，无需安装依赖，双击即用。

## 新增序号工作流（V7.4约定）

> **以后直接丢 JSON 给 AI 即可**，AI 会同步更新以下 4 处，形成闭环：

1. **解析器**（`材料录入桥接工具_v7.4.html`）：新增/扩展解析函数 + 厂家映射
2. **规则文件**（`rules/8.28-V7.4规则更新.xlsx`）：追加序号行，写明厂家/型号/分类
3. **测试用例**（`test_v74_json.js` + `tests/fixtures/`）：新增 expectedData + 文件映射
4. **文档**（`CHANGELOG.md` / `README.md`）：记录新增序号与分类变化

**分类注意**：新增物资类型时先判断是否属于现有 7 类（阀门/对焊法兰/管材/紧固件/垫片/管件/支吊架），若为全新类型（如支吊架），需同步扩展 `classifyProduct` 并更新规则表头分类数。

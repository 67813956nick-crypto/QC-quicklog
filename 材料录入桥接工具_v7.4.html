📋 V7.4 版本使用规则

  

    
一、阀门

    
    
      
  • 产品名称：读取"阀门名称/产品名称/物料描述"中的阀门类型（闸阀/球阀/蝶阀/截止阀/止回阀）
    • 
      
  • 证书出厂编号：读取"证书编号/Certificate No/Report No"后面的编号
    • 
      
  • 材质：读取"体/盖/阀体/阀盖"对应的材质数据（如A216 WCB、A105），去除炉号
    • 
      
  • 规格型号：读取压力等级(CL)+直径(DN)，如"CL150 DN50"
    • 
      
  • 数量：读取"数量/Qty"字段
    • 
      
  • 单位：台
    • 
    


    
二、对焊法兰

    
    
      
  • 产品名称：读取"名称/产品名称/描述"中的"对焊法兰/承插焊法兰"（V7.3新增"产品名称"表头支持，V7.4继续支持）
    • 
      
  • 证书出厂编号：读取"证书编号/Certificate No/生产单编号"后面的编号
    • 
      
  • 材质：读取"材料名称/Name of Mat"后面的材质（如A105、16Mn）
    • 
      
  • 规格型号：读取"规格"后面的值；法兰规格（如WN350-150LB/RF SCH30）保持原样，组合规格（如CL150 DN150 SCH40 RF）自动规整
    • 
      
  • 数量：读取"数量/Quantity"字段
    • 
      
  • 单位：片
    • 
    


    
三、管材

    
    
      
  • 产品名称：读取"产品名称/Description"（输送流体用无缝钢管/输送管/流体输送管）
    • 
      
  • 证书出厂编号：读取"质保书编号/Sheet No/Certificate No"后面的编号
    • 
      
  • 材质：读取"钢级/牌号/标准"中的材质数字（如20），去除标准号
    • 
      
  • 规格型号：读取"规格/Size/Dimension"（如φ26.7*3.91）
    • 
      
  • 数量：读取"总重量/重量/Weight"字段
    • 
      
  • 单位：吨或KG（从数据中自动识别）
    • 
    


    
四、紧固件

    
    
      
  • 产品名称：读取"产品名称"（全螺纹螺栓/螺母）
    • 
      
  • 证书出厂编号：读取"N0/编号"后面的编号
    • 
      
  • 材质：读取"材质"字段（如35CrMoA/30CrMoA）
    • 
      
  • 规格型号：读取"规格"（如M24×135）
    • 
      
  • 数量：读取"数量"字段
    • 
      
  • 单位：套
    • 
    


    
五、垫片

    
    
      
  • 产品名称：读取"产品名称"（带内外环缠绕垫等）
    • 
      
  • 证书出厂编号：读取"订单号"后面的编号
    • 
      
  • 材质：读取"材质"字段（如316L）
    • 
      
  • 规格型号：读取"产品规格"（如AT D DN500 300LB）
    • 
      
  • 数量：读取"产品数量"字段
    • 
      
  • 单位：件
    • 
    


    
六、管件

    
    
      
  • 产品名称：读取"名称/产品名称/物料描述"（弯头/三通/大小头/异径管/管帽/管箍/支管座）
    • 
      
  • 证书出厂编号：读取"证明书编号/质量证明书编号/证书编号/Certificate No/Report No"
    • 
      
  • 材质：读取"材质/材料牌号"字段
    • 
      
  • 规格型号：读取"规格/规格尺寸/规格型号"（如DN600 SCH10S）
    • 
      
  • 数量：读取"数量/Quantity"字段
    • 
      
  • 单位：件
    • 
    


    
通用规则

    
    
      
  • 同一PDF含多条记录时，按页面分别提取，缺失字段用同PDF其他页补充
    • 
      
  • 制造厂家优先从当前表格/section文本中提取，找不到则空着
    • 
      
  • 排除客户名称：中国石油化工、镇海炼化、中海石油等甲方单位不作为制造厂家
    • 
      
  • V7.4新增：青山钢管英文表头无缝管（序号23）、方顿仪表卡套无缝管（序号24）、泰克装箱清单（序号25）
    • 
      
  • 支持MD和JSON两种导入格式，JSON含页眉页脚信息，精度更高
    • 
      
  • 可多次导入不同质保书，数据自动累积；点击"清空数据"重置
